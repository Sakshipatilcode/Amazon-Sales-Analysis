# Amazon-Sales-Analysis
End-to-end data analysis using Excel, Power BI, SQL and Python. 
Amazon Sales Analysis 2022

## Project Overview
Performed end-to-end data analysis on 1.2 lakh 
Amazon sales records to uncover business insights 
on revenue, customer behavior, and sales trends.

---

##  Tools Used
 Tool | Purpose 

*Excel* -- Data Cleaning + Dashboard 
*Power BI* -- Interactive Dashboard 
*MySQL* -- Data Querying 
*Python* -- Data Visualization 

##  Dataset
- Source: Amazon Sales Report 2022 Kaggle.
- Records: 1,20,563 orders
- Columns: Order ID, Date, Category, Size, Amount, Status, Ship-city, Ship-state etc.

##  Data Cleaning Steps
- Removed blank rows and duplicate orders
- Fixed date format and extracted Month & Year
- Simplified order status values
- Filled missing Amount values with 0
- Removed irrelevant columns (SKU, ASIN, 
  Postal Code, Promotion IDs)


##  Key Business Insights
- Total Revenue: ₹1.22 Crore
- Total Orders: 1,20,563
- Top Category: Set (50% of revenue)
- Top State: Maharashtra
- Top City: Bengaluru (1677 orders)
- Peak Month: April 2022
- Most Popular Size: M
- Shipped Successfully:60.5%
- Cancellation Rate: 8.89%
- Avg Order Value: ₹622
- B2C Sales: 99.1%
